# 后端交付说明

本期开发一个供桌面客户端使用的独立服务端：用户登录、License 与设备绑定，以及对话、语音识别、语音合成、静态头像生成、文本向量化五类模型能力。业务数据保存在客户端，不建设云端对话历史、智能体或知识库管理系统。

按以下顺序阅读即可，不需要客户端源码：

| 文档 | 解决的问题 |
| --- | --- |
| [客户端服务 API 实现规范](backend-api-minimal-contract.md) | 客户端调用哪些接口；参数、返回值、鉴权、错误码、SSE、任务、幂等与验收要求 |
| [模型供应商接入规范](backend-model-provider-reference.md) | 服务端调用哪个模型和供应商地址；请求体、结果解析、语音分段及媒体格式规则 |
| [完整 JSON 联调示例](backend-api-examples.json) | 各接口请求/响应，包括完整 1024 维向量；示例不是生产凭据 |

先按 API 规范确认接口与授权流程，再实现供应商接入；不需要了解客户端内部接口、文件路径或模块名称。文档中的“客户端负责”表示服务端无需开发对应业务。

模型基线：对话配置为 DeepSeek `deepseek-flash`；百炼 ASR 为 `qwen3-asr-flash`、TTS 为 `qwen3-tts-flash`（默认 Cherry）、头像为 `wan2.7-image`（一张、2K）、向量为 `text-embedding-v4`（1024 维）。对话模型与地址组合的有效性需联调确认，详见供应商规范。

开发前需确认：账号来源、设备指纹算法、对话模型有效标识、接口限额与超时、至少 24 小时的结果保留期。其余按 API 规范默认值执行；调整时同步修改契约与示例。

管理后台由超级管理员使用，其配置和权限接口另行约定；本文交付包中的 19 项接口仅面向普通客户端。仓库内其他拆分规划、历史审计、客户端改造说明不属于本次后端实现材料。
